#Séries temporelles
1- C'est quoi une série temporelles stationnaire
    Stationnarité: les propriétés statistiques ne varient pas aucours du temps
        Moyenne (constante)
        Variance (mesure de dispersion constante)
    Non-Stationnarité: contraire

2- Décomposotion d'une série temporelles
    Tendance: notée Tt est la dynamique globale de la série
    Saisonnalité: notée St est un cycle
    Erreur ou Résidus ou Bruit: notée Ɛt est un imprévue (catrastrophe naturelle ou recession)
    Le résidu du modèle correspond à la partie de la série temporelle que la décomposition 
        ne permet pas d’expliquer

3- Décomposotion de base
    Additive
        Xt = Tt + St + Ɛt
        Variation avec amplitude constante
    Multiplicative
        Xt = Tt x St x Ɛt
        Variation avec amplitude croissante au cours du temps

4-Analyse des résidus
    Vérifier l'autocorrélation dans les résidus (Test de Ljung-Box)
    Normalité (Test de Shapiro-Wilk)
    Graphiqu de autocorrélation des résidus (ACF et PACF)
    
5-Lissage
    C'est un filtrage
    L'objectif est de retirer le bruit et révéler le signal existant
    On identifie la tendance et les autres composants de la série
    On souhaite réaliser des prédictions
    Types:
        Moyenne mobile => permet de déterminer la tendance de la série
            Moyenne = moyenne des x valeurs précédentes
            Centré = 3 valeurs centrées autour d'une
        Exponentielle =>  
            Xo = xo
            X1 = aX1 + (1-a)Xo
    NB: d'autres méthodes => double ou triple lissage qui permettent d'identifier la 
        tendance et la saisonnalité
        Tous ces modèles sont limités.

6-Modèles plus évoluées (AR, MA, ARMA, ARIMA, SARIMA)
    Stationnarité: moyenne, variance et covariance ne dépendenent pas du temps
    TOUS les modèles précédents doivent etre stationnaire

    "Modèle AR"
        AR = Autoregressive modèle
        Régession à partie des instants (termes) passés
        Formule => Xt = φO + φXt-1 + ...... + φXt-p + Ɛt
        ATTENTION: Vérifer que la série est stationnaire
        Paramètres: p (Nombre de valeurs passées de la série utilisées pour prédire la valeur actuelle.)
            ACF : tends vers 0  
            PACF: S'annule après l'ordre p
        Documentation =>
            https://www.geeksforgeeks.org/autoregressive-ar-model-for-time-series-forecasting/
            https://machinelearningmastery.com/autoregression-models-time-series-forecasting-python/
            https://medium.com/@karen.mossoyan/building-an-autoregression-model-for-time-series-analysis-in-python-49402bdd6d08
            https://blog.quantinsti.com/autoregression/ (finalise sur ARIMA)

    "Modèle MA"
        MA = Moving Average
        Regression sur les erreurs (les séries où les perturbations aléatoires récentes influencent la valeur présente.)
        Formule => Xt = μ + Ɛt + θ1Ɛt-1 + ..... + θqƐt-q
        Paramètres: q (Nombre de termes d’erreur (résidus) passés utilisés pour prédire la valeur actuelle.)
            ACF : S'annule après l'odre q 
            PACF: tends vers 0
        Documentation =>
            https://www.kaggle.com/code/carlmcbrideellis/time-series-a-simple-moving-average-ma-model
            https://blog.gopenai.com/guide-to-time-series-analysis-with-python-2-moving-average-process-784328325e5f
            https://www.geeksforgeeks.org/understanding-the-moving-average-ma-in-time-series-data/

    "Modèle ARMA"
        Composition des 2 précédents (AR et MA)
        ATTENTION: Vérifer que la série est stationnaire
        Formule => Xt = φO + φ1Xt-1 + ..... + φqƐt-q + Ɛt + φ1Ɛt-1 + ..... + φqƐt-q
        NB: la série doit etre stationnaire pour utiliser ce modèle
        Paramètres dans l'ordre: p (valeurs passées) et q (résidus)
            ACF : tends vers 0
            PACF: tends vers 0
        Un passage au log (peut suffire)
            Sinon on la différencie => stationnaire (ARIMA)
        Documentation =>

    "Modèle ARIMA"
        Utilité => permet de différencier une série pour la rendre stationnaire
        I = ordre d'intégration ou ordre de différenciation nécessaire pour obtenir la stationnarité
            On fera un test de Dickey-Fuller pour vérifier la stationnarité
        Paramètres dans l'ordre : 
            p 
            q
            d (Nombre de fois que la série doit être différenciée pour la rendre stationnaire)
        NB: il est idéal pour des séries temporelles non stationnaires
        Théorie => https://github.com/LeCoinStat/100JoursDeML/blob/main/07_Series_Temporelles/01_ARIMA/01_Modele_Arima.ipynb
        Documentation =>

    "Modèle SARIMA"
        Il se distingue du modèle ARIMA par la prise en compte de la saisonnalité
        Documentation =>
        Elle ajuste le modèle statistique à tes données :
        Pour un ARIMA(p, d, q), cela signifie trouver les meilleurs coefficients pour la partie auto-régressive (p), 
            la moyenne mobile (q), et éventuellement la constante, afin de minimiser l’erreur entre les valeurs 
            prédites et les valeurs réelles.
        Elle utilise des méthodes d’optimisation (comme le maximum de vraisemblance) pour trouver ces paramètres 
            automatiquement à partir de tes données.
        Le résultat est un objet "ajusté" (fitted model), qui contient les paramètres estimés et permet de faire des prédictions, d’analyser les résidus, etc.

7-Passage au log
    Role: permet parfois de se passer de la différenciation
    Comment? l'amplitude n'est plus croissante
        en gros on passe d'un modèle multiplicatif à un modèle additif
    Si le graphe n'est pas toujours différencier, on fait la différenctionation (I)

8-Comment sélectionner le bon modèle?
    Méthode de BoX-Jenkins
        Auto corrélation:
            C'est la vérification de la correlation d'une variable avec elle meme à différent moment
        ACF
            Corrélation de Pearson entre les valeurs de la série
            Inc: entre xt et xt-2, il prend en compte xt-1, ce qui est un problème
        PACF
            Corrélation de Pearson entre les valeurs de la série SANS l'impact des autres valeurs de la série
            C'est un modèle linéaire avec des coffecient a1, a2 etc....
            Xt = a1 Xt-1 + a2 Xt-2 + a1 Xt-3 + Vt

9-Les critères d'informations
    Objectif => les minimiser au maximum
    Il permettent de décrire le modèle avec le minimum de variable/valeur possible
    Ils sont:
        AIC = 2k - 2ln(K)
        BIC = -2ln(L) + k.ln(N)
        HQC = -2Lmax + 2kln(ln(n))
            k = nombre de variables du modèle
            L = maximum de vraissemblance
            N = nombre d'observation des données

10-Métriques
    MAP (pourcentage d'erreurs sur les prévision du modèle)

*********** Quelques definitions complexes **********
Graphe ACF => L'ACF mesure la corrélation entre une séquence et elle-même à"
    "différentes périodes de temps. Autrement dit, elle permet d'évaluer la similitude entre"
    "les observations en fonction du décalage de temps entre elles

La PACF est une corrélation qui exclut l'effet des termes intermédiaires. "
    "C'est-à-dire qu'elle est une mesure de la corrélation entre des observations à un "
    "certain intervalle, en tenant compte des valeurs à des intervalles plus courts.

MSE (Mean Squared Error, Erreur Quadratique Moyenne)        MSE = (1/n) × Σ(yi - ŷi)²
Mesure la moyenne des carrés des écarts entre les valeurs observées et les valeurs prédites.
Signification : plus la valeur est faible, plus le modèle est précis. Le MSE pénalise 
    fortement les erreurs importantes (car il élève les écarts au carré).

RMSE (Root Mean Squared Error, Racine de l’Erreur Quadratique Moyenne)      RMSE = √(MSE) = √[(1/n) × Σ(yi - ŷi)²]
C’est simplement la racine carrée du MSE.
Signification : elle ramène l’erreur dans l’unité de la variable d’origine, 
    ce qui facilite l’interprétation. Plus la valeur est faible, meilleure est la performance du modèle.

MAE (Mean Absolute Error, Erreur Absolue Moyenne)       MAE = (1/n) × Σ|yi - ŷi|
Mesure la moyenne des valeurs absolues des écarts entre les valeurs observées et les valeurs prédites.
Signification : elle donne une idée de l’erreur moyenne, sans sur-pénaliser les gros écarts, 
    contrairement au MSE

R² Score (Coefficient de détermination) 
    R² = 1 - (SS_res / SS_tot)
    où SS_res = Σ(yi - ŷi)²  (somme des carrés des résidus)
    et SS_tot = Σ(yi - ȳ)²   (somme totale des carrés)
C'est la proportion de la variance expliquée par le modèle.
Varie entre -∞ et 1
R² = 1 : modèle parfait
R² = 0 : modèle équivalent à la moyenne
R² < 0 : modèle pire que la moyenne

MAPE (Mean Absolute Percentage Error)       MAPE = (100/n) × Σ|((yi - ŷi) / yi)|
C'est le pourcentage d'erreur absolue moyenne.
Plus bas = meilleur

Accuracy (Exactitude)
C'est la proportion de prédictions correctes.
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Varie entre 0 et 1
Plus élevé = meilleur

Precision.   Precision = TP / (TP + FP)
Répond à : "Parmi les prédictions positives, combien sont correctes ?"
Importante quand le coût des faux positifs est élevé
Plus élevé = meilleur

Recall (Sensibilité)        Recall = TP / (TP + FN)
Répond à : "Parmi les vrais positifs, combien ont été détectés ?"
Importante quand le coût des faux négatifs est élevé
Plus élevé = meilleur

Critère d'Information d'Akaike (AIC) : Mesure la qualité relative d'un modèle en tenant "
    "compte de sa complexité. Un AIC plus faible indique un meilleur équilibre entre ajustement et simplicité.

Critère d'Information Bayésien (BIC) : Semblable à l'AIC, mais pénalise davantage "
    "la complexité du modèle. Un BIC plus faible est préférable.

Le test de Ljung-Box teste l'absence d'autocorrélation dans les résidus. Nous voulons que "
    "les résidus soient indépendants les uns des autres. Vérifier que les résidus suivent un bruit blanc
Un résidu = différence entre valeur observée et valeur prédite

Le test de Shapiro-Wilk permet de vérifier la normalité. L'aspect de normalité fait "
    "référence à la distribution des résidus. Dans un bon modèle, nous attendons que les résidus "
    "suivent une distribution normale

1-Défintion d'une série temporelle
    Def => séquence de donées collectées à intervalles réguliers à travers le temps
    Objectif => identifier à travers des données les tendances, les cycles, des variations saisonnières
        et utiliser toutes ces informations pour faire des prédictions
    Exemples de séries temporelles:

            Cours de cloture quotidiens d'une action au fil du temps
            Températures moyennes mensuelles à un endroit données
        Multivariée =>
            Cours quotidiens des actions et le volume de transactions au fil du temps
            Mesures météorologiques horaires comprenant température, l'humidité et ka vitesse du vent

    Modèles linéaires: (tendance et saisonnalité CLAIRES)

        Modèles de moyenne mobile (MA)

        Modèles de moyennes mobiles intégrées autoregressives saisonnières (SARIMA)
    Modèles: (on veut identifier des tendances COMPLEXES au sein des données)
        Les réseaux de neuronnes récurrents (LSTM)

    Analyse multivariée: capturent des interactions complexes entre les caractéristiques d'entrée 
        et la variable cible.
    Données irrégulières et manquantes

********* Comment optimiser le modèle?? **********
1. Identifier les hyperparamètres à optimiser
Pour un modèle LSTM, les principaux hyperparamètres sont :
    Taille de la fenêtre temporelle (window size)
    Nombre de couches LSTM
    Nombre d’unités par couche
    Fonctions d’activation
    Taux d’apprentissage (learning rate)
    Taille du batch
    Nombre d’époques
    Taux de Dropout
    Type d’optimiseur (Adam, RMSprop, etc.)

2. Choisir une méthode d’optimisation
    A. Recherche exhaustive (Grid Search)
        Tester toutes les combinaisons possibles d’un ensemble de valeurs pour chaque hyperparamètre.
        Avantage : Simple à comprendre.
        Inconvénient : Très coûteux en temps de calcul, surtout pour les réseaux profonds.
    B. Recherche aléatoire (Random Search)
        Tester des combinaisons aléatoires dans l’espace des hyperparamètres.
        Plus efficace que le grid search pour des espaces de recherche larges
    C. Algorithmes évolutifs (ex : Algorithme génétique)
        Utilisent des principes de sélection naturelle pour explorer l’espace des solutions et améliorer progressivement les combinaisons d’hyperparamètres.
    D. Outils spécialisés (Keras Tuner, Optuna, Hyperopt, etc.)
        Automatisent et optimisent la recherche des meilleurs hyperparamètres en utilisant des stratégies avancées (Hyperband, Bayesian optimization…).
        Keras Tuner est particulièrement adapté pour les modèles Keras/TensorFlow et les séries temporelles.

********* Les paramètres d'un LSTM *********
Voici une explication détaillée de chaque paramètre dans le contexte de la prédiction de séries temporelles avec un LSTM :
1. Taille de la fenêtre temporelle (window size)
Rôle : Nombre de pas de temps historiques utilisés pour prédire le pas suivant
Impact :
    Trop petite → Modèle manque de contexte temporel
    Trop grande → Bruit, complexité inutile, risque de mémoriser des motifs non pertinents
Valeur typique : 7-365 jours selon la fréquence des données

2. Nombre de couches LSTM 
Rôle : Profondeur du réseau pour capturer des dépendances complexes
Impact :
    1 couche : Suffisant pour des motifs simples
    2-3 couches : Capture des hiérarchies temporelles (court/moyen/long terme)
    3 couches : Risque de surapprentissage, nécessite beaucoup de données
Valeur typique : 1-3 couches pour la plupart des séries temporelles

3. Nombre d'unités par couche
Rôle : Capacité de mémorisation et complexité des motifs capturés
Impact :
    Faible (32-64) : Modèle simple, évite le surapprentissage
    Élevé (128-256) : Capture des relations complexes mais risque d'overfitting
Valeur typique : 50-200 unités selon la complexité de la série

4. Fonctions d'activation
Rôle : Introduire de la non-linéarité dans les calculs
Choix courants :
    tanh : Standard pour les portes LSTM (valeurs entre -1 et 1)
    relu : Convergence plus rapide mais risque de "dying ReLU"
    sigmoid : Utilisée pour les portes (oubli/mise à jour)
Impact : tanh généralement meilleure pour les séries temporelles

5. Taux d'apprentissage (learning rate)
Rôle : Taille des pas d'optimisation pendant l'entraînement
Impact :
    Trop élevé (0.1) → Oscillations, divergence
    Trop faible (1e-5) → Convergence lente, risque de minimum local
Valeur typique : 1e-3 à 1e-5 (Adam utilise souvent 3e-4)

6. Taille du batch
Rôle : Nombre d'échantillons traités avant mise à jour des poids
Impact :
    Petit batch (16-32) : Convergence plus stable mais plus lent
    Grand batch (512+) : Accélération mais convergence moins précise
Valeur typique : 32-128 pour les séries temporelles

7. Nombre d'époques
Rôle : Nombre de passes complètes sur le jeu d'entraînement
Impact :
    Insuffisant → Sous-apprentissage
    Excessif → Surapprentissage
Optimisation : Utiliser l'early stopping (patience=10-20)

8. Taux de Dropout
Rôle : Régularisation en désactivant aléatoirement des neurones
Impact :
    0-0.2 : Peu d'effet régularisateur
    0.3-0.5 : Bon compromis pour éviter l'overfitting
    0.5 : Risque de sous-apprentissage
Spécifique LSTM : Peut utiliser Dropout récurrent (entre les timesteps)

9. Type d'optimiseur
Rôle : Algorithme de mise à jour des poids
Choix courants :
    adam : Adaptatif, bon compromis vitesse/précision
    rmsprop : Efficace pour les problèmes récurrents
SGD : Plus lent mais convergence plus stable
Recommandation : Adam (avec décroissance du learning rate) pour 90% des cas

        StandardScaler
            Centre les données autour de 0, écart-type 1.
            Moyenne ≈ 0, écart-type ≈ 1
            Méthodes basées sur distance (SVM, PCA, régression, LSTM…)
            Quand la distribution suit une loi normale (belle gaussienne)
        MinMaxScaler
            Ramène les données dans un intervalle donné (par défaut [0, 1])
            Tous les points sont dans [0, 1]
            Méthodes nécessitant un intervalle borné (réseaux de neurones, images, etc.)
            Quand les données doivent être entre 0 et 1

Pourquoi on peut avoir des résultats différets pour des données identiques?
Réponses:
    -Comportement aléatoire d’un Random Forest
        Chaque arbre du Random Forest utilise un tirage aléatoire
            sélection aléatoire de sous-ensembles de variables (max_features)
        Si tu ne fixes pas un random_state, chaque exécution donne des résultats légèrement différents
    -Randomness dans la validation croisée
        La validation croisée (cv) induit de la variabilité si :
            les plis ne sont pas fixés,
        il y a du shuffle dans le K‑fold, ou si n_jobs > 1 (parallélisme non déterministe)

************Modèle ADRL************
0. Défintion:
    C'est un modèle ARDL (Autoregressive Distributed Lag model) : c’est un outil très puissant pour modéliser les relations 
entre séries temporelles économiques, notamment quand tu veux analyser les effets à court et long terme entre deux 
ou plusieurs variables, même lorsqu’elles ne sont pas stationnaires au même ordre.

1. Qu'est-ce que le modèle ARDL ?
    Le modèle ARDL(p, q) permet de relier une variable dépendante à ses propres retards (autoregressive = AR) ainsi qu’aux 
retards d’une ou plusieurs variables explicatives (distributed lag = DL).

2. Pourquoi utiliser un ARDL ?
Le grand avantage du modèle ARDL est qu’il peut être utilisé :lorsque les séries sont de type I(0) (stationnaires) 
ou I(1) (non stationnaires),mais pas I(2) ! (modèle invalide si une des séries est I(2)).
👉 Tu n’as pas besoin que toutes les séries soient stationnaires au même ordre, contrairement à un VECM.

3. Conditions d’utilisation du modèle ARDL
    Étape	Action
    1.	Tester la stationnarité avec ADF, PP, KPSS
    2.	Vérifier que aucune variable n'est I(2)
    3.	Estimer le modèle ARDL(p, q)
    4.	Tester l’existence d’une relation de long terme avec le test de Borns-Pesaran-Shin (BPS) (aussi appelé bounds test)
    5.	Estimer les effets de long terme et d’ajustement court terme via l’ECM (modèle à correction d’erreur)

4. Composantes du modèle ARDL
    Partie courte période : effets dynamiques immédiats via les retards.
    Partie long terme : si relation stable entre les niveaux → co-intégration.
    ECM (Error Correction Model) : modèle dérivé de l’ARDL qui montre à quelle vitesse la variable dépendante revient à l’équilibre de long terme.

5. Test de co-intégration : Bounds Test.  (Penser aussi au test de Fisher)
Proposé par Pesaran, Shin et Smith (2001).
Hypothèses :
    H0 : Pas de relation de long terme (pas de co-intégration)
    H1 : Il existe une relation de long terme
    Résultat :
        Si la statistique F > seuil supérieur → co-intégration confirmée
        Si F < seuil inférieur → pas de co-intégration
        Si F entre les deux → zone d’incertitude

===>>>Étapes d’analyse:
0 - Statistiques descriptives sous forme de tableau
1 - Tests de racine unitaire ou de stationnarité : ADF ou PP pour vérifier que chaque série est I(0) ou I(1), mais pas I(2)
2 - Sélection des retards optimaux (p et q) via critères d’information (AIC, BIC).
3 - Test des bornes de cointegration (Pesaran–Shin–Smith) :
    Construire le modèle UECM (Unrestricted Error Correction Model).
    Calculer le F-statistique pour tester l’hypothèse nulle (pas de relation de long‑terme).
    Si F > borne supérieure → cointegration, relation de long terme présente ; si F < borne inférieure → pas de relation ;
    si entre les deux → conclusion incertaine 
4 - Estimation du modèle ECM : introduit un terme de correction d’erreur (ECTₜ₋₁) pour capturer la dynamique de retour à l’équilibre à court terme à taux λ (idéalement négatif et significatif) .
5 - Tests de diagnostic : validité des résidus (autocorrélation, hétéroscédasticité, normalité…), stabilité et robustesse.

===>>>code python
import pandas as pd
from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.ardl import ARDL, UECM

# 1. Charger données
df = pd.read_csv('data.csv', parse_dates=['Date'], index_col='Date')
y = df['inflation']
x = df['chomage']

# 2. Tests de stationnarité
print('ADF inflation:', adfuller(y)[1])
print('ADF chômage:', adfuller(x)[1])

# 3. Trouver ordre optimal
from statsmodels.tsa.ardl import ardl_select_order
sel = ardl_select_order(y, exog=x, maxlag=5, ic='aic')
print(sel.model.fit().summary())

# 4. Ajuster un ARDL(p,q)
model = ARDL(y, lags=sel.ar_lags, exog=x, exog_lags=sel.exog_lags).fit()
print(model.summary())

# 5. Test des bornes de cointegration
uecm = model.to_uecm()
bt = uecm.fit().bounds_test(case=3)
print(bt.stat, bt.crit_vals)

# 6. Si cointegration détectée → estimer ECM
res = uecm.fit()
print(res.summary())

Description synthétique et cas d'utilisation (VAR, VECM, ADRL)
VAR (Vector Autoregressive Model)
    Pour modéliser les dynamiques entre plusieurs séries temporelles stationnaires (I(0)).
    Chaque variable dépend de ses propres retards et ceux des autres.
    Pas adapté aux séries non stationnaires sans cointégration, car il peut donner des résultats trompeurs.
    À utiliser quand toutes les séries sont stationnaires et que l'intérêt porte sur les relations à court terme entre les variables.
VECM (Vector Error Correction Model)
    Pour séries non stationnaires (I(1)) qui sont co-intégrées (partagent une relation d’équilibre de long terme).
    Modélise à la fois l’ajustement vers l’équilibre de long terme (terme d'erreur de correction) et les dynamiques à court terme.
    À utiliser quand toutes les séries sont I(1) et que la cointégration existe (test de Johansen positif).
ARDL (Autoregressive Distributed Lag Model)
    Supporte les séries stationnaires (I(0)), non stationnaires (I(1)), ou un mélange (pas de I(2)).
    Permet de tester la présence de co-intégration avec le bound test de Pesaran.
    Pratique pour explorer à la fois le court terme et le long terme, même avec peu de variables, ou quand les séries ont des ordres d’intégration différents.
    À utiliser si vos séries sont de types mixtes (I(0) et I(1)), ou si leur intégration n’est pas homogène.

Choix (entre VAR, VECM et ADRL) selon la stationnarité des séries
    Deux séries sont stationnaires (I(0)) :
        VAR est adapté pour modéliser leurs interactions dynamiques à court terme.
    Deux séries sont non stationnaires (I(1)), et co-intégrées :
        Utilisez VECM pour prendre en compte le long terme et l’ajustement vers l’équilibre.
    Deux séries sont non stationnaires (I(1)), sans co-intégration :
        Appliquez VAR sur les séries différenciées (pour les rendre stationnaires).
    L’une est stationnaire (I(0)) et l’autre ne l’est pas (I(1)), aucune n’est I(2) :
        ARDL est LE choix le plus robuste, car il gère le mix I(0)/I(1) et permet de tester la co-intégration.

Résumé opérationnel
    VAR : dynamiques de court terme, séries stationnaires.
    VECM : dynamiques court et long terme, séries I(1) et co-intégrées.
    ARDL : cas mixte, ou séries I(0) et I(1), explore court et long terme.

Cas d'utilisation exceptionnel
    Si vous avez deux séries non stationnaires, testez la co-intégration :
        Co-intégrées ? VECM
        Pas co-intégrées ? VAR sur les différenciées, ou ARDL
            Séries de types mixtes ? ARDL est le plus flexible.

*****************Test de cointégration de Pearson*****************
    -Definition:
        Le test de cointégration aux bornes (bounds test) de Pesaran et al. (2001) est une méthode puissante pour vérifier 
        l’existence d’une relation de long terme (cointégration) entre deux (ou plusieurs) séries temporelles, même si elles 
        ne sont pas toutes du même ordre d’intégration (I(0) ou I(1)) tant qu’aucune n’est I(2)
    -Etapes:
        --Test de stationnarité préalable 
            Maxim 1 différentiation
        --Choix du nombre de retards (lags) optimaux
            Déterminez les lags appropriés à inclure, avec des critères comme AIC ou BIC/SIC.
            Cela garantit que le modèle capte correctement la dynamique intertemporelle.
        --Estimation du modèle ARDL
        --Calcul de la statistique F des bornes
            On teste l’hypothèse : Pas de cointégration (λ1 = λ2 = 0) versus existence d’une relation de long terme (au moins l’un ≠ 0).
            La statistique F comparera la significativité conjointe des coefficients retardés au niveau
        --Comparaison avec les tables de Pesaran
            Il existe deux bornes de seuil critique :
                Borne inférieure : hypothèse que toutes les variables sont I(0)
                Borne supérieure : hypothèse que toutes sont I(1)
            Règle de décision :
                Si F < borne inférieure : pas de cointégration
                Si F > borne supérieure : cointégration confirmée
                Si F entre les deux : résultat indécis, pas de conclusion nette

📊 CAS 1 : I(0) et I(0) - Séries Stationnaires
❌ Cointégration : NON

Raison : Les séries I(0) sont déjà stationnaires, donc pas de cointégration possible
Principe : La cointégration nécessite des séries non-stationnaires qui convergent vers un équilibre

✅ Tests Recommandés :
    Corrélation de Pearson/Spearman (Un coefficient élevé (en valeur absolue) suggère une association de court terme, mais n’indique ni la direction de la causalité ni de mécanisme dynamique direct)
    Test de causalité de Granger (sur séries en niveau) =>permet de vérifier si les valeurs passées de l’une aident à prédire l’autre, dans un modèle restreint à des séries stationnaires.
    Régression linéaire classique avec tests de robustesse

🎯 Modèles Appropriés :
    Régression Linéaire Multiple (OLS)
    Modèle VAR en niveau (si plusieurs variables)
        permet d’estimer les interactions de court terme et d’analyser les réponses dynamiques aux chocs via les fonctions de réponse impulsionnelle (IRF).
        permet de modéliser l’évolution de chaque série en fonction de ses propres retards et de ceux de l’autre.
    Modèles ARMA pour la prévision individuelle

Interprétation des résultats
    Corrélation : Si la corrélation est significative, il existe un lien de dépendance de court terme. Attention, cela ne signifie pas causalité.
    Granger : Si la causalité de Granger est significative (p-valeur < 0.05), cela signifie que les valeurs passées de la série X apportent de l’information pour prédire la série Y au-delà des propres retards de Y.
    VAR :
        Les coefficients croisés (effet de X_t-1 sur Y_t) permettent d’identifier et de quantifier ces dépendances de court terme.
        La dynamique globale (impulse response function) permet d’analyser la propagation des chocs.
        Le critère AIC minimise l’erreur de prévision mais peut sélectionner des modèles plus complexes.
        BIC favorise la parcimonie (modèle simple).
        Les résidus doivent se comporter comme un bruit blanc pour valider le modèle.
        Interpréter les coefficients du VAR pour comprendre l’effet dynamique des variables entre elles
    Régression linéaire : Vous pouvez également estimer une simple régression linéaire (en niveau), mais l’interprétation est celle d’une dépendance moyenne, sans notion de causalité ni dynamique.




📊 CAS 2 : I(0) et I(1) - Ordres Mixtes
⚠️ Cointégration Classique : NON

Problème : Test d'Engle-Granger inadapté (nécessite toutes I(1))

✅ Tests Recommandés :
    🏆 ARDL Bounds Test (Pesaran et al., 2001) - MÉTHODE DE RÉFÉRENCE
    Test de causalité de Granger (après transformation appropriée)

🎯 Modèles Appropriés :
    🥇 Modèle ARDL (AutoRegressive Distributed Lag)
    Modèle ECM-ARDL si cointégration détectée
    Régression avec variables instrumentales (si endogénéité)

📚 Justification Académique :
    Avantage ARDL : "Unlike Johansen's method, ARDL does not require pre-testing for the exact order of integration (I(0) or I(1)) for all series"
    Flexibilité : Gère les ordres d'intégration mixtes sans problème

1. Hypothèses de base
    Ordre d’intégration :
        Une variable (ex. : X) est I(0), donc stationnaire.
        Une variable (ex. : Y) est I(1), donc non stationnaire (mais stationnaire après une différenciation).
    Aucune des séries n’est I(2) ou d’ordre supérieur, sinon les modèles classiques ne sont pas applicables.
    Relation potentielle de long terme : Les séries peuvent être reliées par une relation d’équilibre (cointégration) malgré la non-stationnarité de l’une d’elles.
2. Tests statistiques à réaliser
    Tests de racine unitaire (pour déterminer I(0) ou I(1)) :
        Test Augmented Dickey-Fuller (ADF) [H0 : racine unitaire ⇒ non stationnaire]
        Test KPSS [H0 : stationnarité]
        Interpréter les deux en sens croisé pour lever l’ambiguïté.
    Test de cointégration (relation à long terme) :
        Bounds Test de Pesaran et al. (ARDL Bounds Test), recommandé pour variables d’ordre d’intégration mixte.
    Tests diagnostics classiques après modélisation :
        Normalité des résidus (Shapiro-Wilk).
        Autocorrélation des résidus (Durbin-Watson ou Breusch-Godfrey).
        Hétéroscédasticité des résidus (Breusch-Pagan ou White).
3. Modèles utilisables
    ARDL (Autoregressive Distributed Lag) :
        Approprié quand l’une des variables est I(0) et l’autre I(1) (aucune I(2)).
        Permet d’estimer une relation de long terme et de court terme simultanément.
4. Protocole d’analyse et interprétation des résultats
Tester et documenter la stationnarité de chaque série
    Si X est I(0) et Y est I(1), continuer avec les séries en niveau pour l’ARDL/bounds test.
Sélection de l’ordre optimal (p et q) pour l’ARDL via un critère d’information (AIC, BIC, etc.)
Tester la cointégration par le Bounds Test :
    Si la statistique F > borne supérieure (I(1)) ⇒ relation de long terme (cointégration).
    Si la stat < borne inférieure (I(0)) ⇒ pas de relation de long terme.
    Sinon, résultat non concluant.
Si cointégration détectée :
    Estimation du modèle ECM-ARDL (modèle à correction d’erreur).
    Interpréter le coefficient du terme d’ajustement : vitesse de retour à l’équilibre attendu négative et significative.
    Coefficients long terme : effet permanent d’une variable sur l’autre.
    Coefficients court terme : effets temporaires/dynamiques.
Si pas de cointégration :
    Se restreindre à une modélisation en différences ou court terme uniquement.
Diagnostics post-estimation :
    Normalité, autocorrélation, hétéroscédasticité des résidus.
    Visualisation graphique recommandée (qqplot, ACF, histogramme des résidus).
Interprétation :
    Si la vitesse d’ajustement (erreur correction) est négative et significative, la relation de long terme est valide.
    Les coefficients de court terme informent sur l’impact immédiat, ceux du long terme sur la relation d’équilibre.
    Précision sur le traitement des séries

NB: role du lag order => le nombre maximal de retards (lags) à considérer pour chacune des variables exogènes 
(c'est-à-dire les variables explicatives, souvent notées X)

SOLUTIONS => 
    1- Faire   les relations en différences, par exemple avec un modèle ARDL sans terme de correction d’erreur (ECM).
    2- Faire le test de Johansen
    3- Faire un modèle VAR en première différence,


Testons la solution 1:
Un modèle ARDL en différences est une application particulière du modèle ARDL (AutoRegressive Distributed Lag) qui 
permet d'étudier la dynamique à court terme entre une variable dépendante et des variables explicatives, 
quand ces séries sont non stationnaires en niveau mais stationnaires en première différence (I(1)) ou qu’il n’y a 
pas de cointégration détectée.

Qu'est-ce qu'un modèle ARDL en différences ?
    -Le modèle ARDL classique inclut lags des variables en niveau, ce qui permet de capturer relations long terme et court terme lorsque les variables sont cointégrées.
    -Quand il n'y a pas de cointégration, on ne peut pas estimer directement les relations de long terme, et on s’intéresse alors plutôt aux relations dynamiques à court terme.
    -Pour cela, on modélise les variables en première différence (noté Δ), ce qui permet de travailler avec des séries stationnaires.
    -Le modèle ARDL en différences s’apparente à un modèle dynamique où la variable dépendante en différence est expliquée par des différenciations retardées de la dépendante et des explications.



Un lag significatif (ou « retard significatif ») correspond, dans un modèle de séries temporelles dynamique 
(comme les modèles VAR, ARDL, etc.), à une variable explicative retardée (par exemple X_{t-1}, X_{t-2}, ...) 
dont le coefficient estimé est statistiquement significatif, c’est-à-dire que sa valeur associée (p-value) est 
inférieure à un seuil habituellement fixé à 5 % (p < 0.05)

Modèle VECM
    *Dès qu’au moins une relation de cointégration est détectée entre tes séries I(1) (par test de Johansen ou Engle-Granger), 
    le VECM est la méthode scientifiquement appropriée pour modéliser à la fois :
        -L’ajustement à long terme (retour vers la relation d’équilibre)
        -La dynamique à court terme (interactions immédiates entre les variations des séries)

    *Paramètre => determinisc
    Ce paramètre indique si tu inclus une constante et/ou une tendance dans :
        La relation de cointégration (équilibre long terme)
        Les équations en différences (court terme)
        Les choix courants (nomenclature statsmodels) sont :
            "co" : constante dans la relation de cointégration seulement (à privilégier pour macroéconomie, très utilisé)
            "ci" : constante dans l'équation en différences uniquement
            "lo" : constante dans la relation de cointégration et dans l'équation en différences
    CHOIX: 2 cas possibles
        1-Si tes séries croissent autour d’un niveau stable ou présentent simplement un niveau moyen non nul, 
        utilise "co" (constante dans la cointégration) ;
        2-Si tu observes une tendance linéaire déterministe forte dans les niveaux des séries (ex. : PIB réel, population),
        teste "lo" ou inclue une tendance, mais cela est plus rare pour des séries économiques déjà transformées (comme log ou inflation) ;
    
    *Paramètre =>rank
    Le rang de cointégration r correspond au nombre de relations d’équilibre à long terme
        Par exemple, pour deux séries : r = 0 (pas de cointégration), r = 1 (une relation d’équilibre), 
        r = 2 (cas limite, extrêmement rare : les deux séries sont elles-mêmes stationnaires)
